# Client Project Management Platform
A web-based project management and CRM platform that allows multiple companies to subscribe and manage their clients, projects, tasks, and team collaboration in one place.

Each company can:
   - Create its profile (logo, details, services, etc.)
   - Create projects and Add managers, employees, and clients in project via email invitation
   - Manage projects and tasks
   - Track project progress, deadlines, and statuses
   - Track project tasks/tickets in kanban board
   - Do comments on task/tickets

# Target Users
    Admin, Managers, Clients, Employees (Developers & QAs)
